## 1. 도구 소개

**YOLO Detection 라벨링 툴**은 이미지에 바운딩 박스(Bounding Box)를 그려 YOLO 객체 탐지 모델의 학습 데이터를 만드는 브라우저 기반 도구입니다.

**결과물**

작업을 저장하면 다음 구조의 ZIP 파일이 생성됩니다.

```
annotations_2024-01-15.zip
├── json/          ← 전체 어노테이션 데이터 (백업 및 재개용)
│   ├── image1.json
│   └── image2.json
└── labels/        ← YOLO 학습용 TXT 파일 (객체가 있는 이미지만)
    └── image1.txt
```

**요구사항**

- Python 3 (로컬 서버 실행용)
- Chrome 브라우저 권장

> [!NOTE]
> 이 도구는 100% 로컬에서 동작합니다. 인터넷 연결이나 별도 서버 설치가 필요하지 않습니다.

## 2. 실행 방법

터미널(명령 프롬프트)에서 아래 명령어를 실행합니다.

```bash
cd data_labeler
python -m http.server 8080
```

그 다음 브라우저에서 `http://localhost:8080` 으로 접속합니다.

> [!WARNING]
> `index.html` 파일을 브라우저에서 **직접 열면(`file://`)** 폴더 선택 기능이 차단되어 동작하지 않습니다. 반드시 위의 방법으로 실행하세요.

서버를 종료할 때는 터미널에서 `Ctrl + C` 를 누릅니다.

## 3. UI 레이아웃 한눈에 보기

화면은 크게 5개 영역으로 구성됩니다.

| 영역 | 위치 | 주요 요소 |
|------|------|-----------|
| **헤더** | 상단 전체 | Config 열기, 이미지 폴더 열기, 라벨 폴더 열기, 전체 저장(ZIP), 이전/다음 버튼, 단축키 설정(톱니바퀴) |
| **왼쪽 사이드바** | 좌측 (토글) | Label Viewer (JSON/YOLO 탭), Image List (그리드/목록 뷰) |
| **캔버스** | 중앙 | 이미지 표시, 모드 표시기(노란 배너), 십자선 가이드 |
| **오른쪽 패널** | 우측 | 클래스 선택기 + 색상 점, 객체 목록, 상세정보(좌표 편집) |
| **푸터** | 하단 전체 | 파일명, 이미지 크기, 파일 용량, 마우스 좌표, 줌 비율 |

왼쪽 사이드바는 아이콘 버튼을 클릭해 열고 닫을 수 있으며, 경계선을 드래그해 너비를 조절할 수 있습니다.

## 4. 시작하기: 3단계 로드 순서

> [!IMPORTANT]
> 아래 순서를 반드시 지켜야 합니다. 순서를 건너뛰면 버튼이 비활성화 상태로 남습니다.

### ① Config 파일 로드 (필수)

헤더의 **Config 열기** 버튼을 클릭하고 JSON 파일을 선택합니다.

**Config 형식** — 클래스 이름을 나열한 단순 JSON 배열입니다.

```json
["person", "car", "truck", "bicycle", "motorcycle"]
```

- 배열의 순서가 YOLO 클래스 인덱스가 됩니다 (첫 번째 = 0번).
- 로드에 성공하면 버튼이 초록색 **"Config 로드됨"** 으로 바뀝니다.

**제공되는 예제 Config 파일** (`config/` 폴더 안)

| 파일명 | 클래스 |
|--------|--------|
| `detection_config.json` | person, car, truck, bicycle, motorcycle |
| `multi_cls_config.json` | person, vehicle |
| `pallet_config.json` | pallet |
| `pose_config.json` | person |

> [!WARNING]
> Config 형식이 잘못되면 오류 메시지가 표시됩니다. 반드시 `[...]` 형태의 JSON 배열이어야 하며, 빈 배열이나 문자열이 아닌 값은 허용되지 않습니다.

### ② 이미지 폴더 열기 (필수)

Config 로드 후 활성화된 **이미지 폴더 열기** 버튼을 클릭하고 이미지가 담긴 폴더를 선택합니다.

- PNG, JPG, JPEG 파일을 인식합니다.
- 로딩 중에는 `이미지 로딩: 3/10` 형태의 진행 알림이 표시됩니다.
- 완료되면 버튼이 초록색 **"폴더 로드됨"** 으로 바뀌고 첫 번째 이미지가 캔버스에 표시됩니다.

> [!NOTE]
> 하위 폴더 안의 이미지는 인식되지 않습니다. 이미지 파일이 한 폴더 안에 있어야 합니다.

### ③ 라벨 폴더 열기 (선택 — 작업 이어하기)

이전에 저장한 ZIP 파일의 압축을 해제한 뒤, **라벨 폴더 열기** 버튼을 클릭하고 해제된 폴더를 선택합니다.

툴이 자동으로 `json/` 하위 폴더를 감지해 이전 어노테이션을 복원합니다. 자세한 내용은 [9. 작업 이어하기](#9-작업-이어하기)를 참고하세요.

## 5. 라벨링 방법

### 클래스 선택

오른쪽 패널 상단의 드롭다운에서 클래스를 선택하거나, 숫자키 `1`~`9`로 즉시 선택합니다.

- 숫자키는 Config 배열의 순서를 따릅니다 (1번 = 첫 번째 클래스).
- 숫자키를 누르면 해당 클래스로 선택되면서 자동으로 그리기 모드로 진입합니다.

> [!TIP]
> 숫자키를 활용하면 클래스 선택과 그리기 모드 진입을 한 번에 할 수 있어 작업 속도가 빨라집니다.

### 바운딩 박스 그리기

1. **+ 객체 추가** 버튼을 클릭하거나, 숫자키로 클래스를 선택합니다.
2. 캔버스 상단에 노란색 배너 **"BBOX 그리기 모드"** 가 나타납니다.
3. 캔버스에서 **클릭한 채로 드래그** 하여 바운딩 박스를 그립니다.
4. 마우스를 놓으면 객체가 생성되고 자동으로 선택됩니다.

> [!WARNING]
> 바운딩 박스의 최소 크기는 **10×10 픽셀**입니다. 그보다 작으면 오류 메시지와 함께 취소됩니다.

`Escape` 키를 누르면 그리기 모드를 취소할 수 있습니다.

### 바운딩 박스 편집

**크기 조정**: 선택된 박스의 네 모서리에 핸들이 표시됩니다. 핸들을 드래그하여 크기를 조정합니다.

**좌표 직접 수정**: 오른쪽 패널 하단 상세정보에서 X1, Y1, X2, Y2 값을 직접 입력할 수 있습니다.

**클래스 변경**: 상세정보의 클래스 드롭다운에서 다른 클래스로 변경합니다.

박스를 클릭하면 선택되고, 빈 캔버스 영역을 클릭하면 선택이 해제됩니다.

### 객체 목록 관리

오른쪽 패널 중간의 객체 목록에서 현재 이미지의 모든 객체를 확인하고 관리합니다.

| 버튼 | 기능 |
|------|------|
| 눈 아이콘 | 객체 숨기기 / 보이기 토글 |
| 휴지통 아이콘 | 객체 삭제 (확인 모달 표시) |
| `Delete` / `Backspace` | 선택된 객체 삭제 |

> [!NOTE]
> 숨김 처리된 객체는 캔버스에서 보이지 않지만 저장할 때 데이터에는 포함됩니다. 완전히 제거하려면 삭제하세요.

### 캔버스 탐색 (줌 / 패닝)

| 동작 | 결과 |
|------|------|
| 마우스 휠 | 줌 인 / 줌 아웃 (마우스 커서 위치 기준) |
| `Alt` + 드래그 | 캔버스 이동 (패닝) |

이미지를 전환하면 캔버스 뷰가 자동으로 초기화됩니다.

## 6. 이미지 탐색 및 진행 확인

### 이미지 이동

- 헤더의 **이전 / 다음** 화살표 버튼 클릭
- 키보드: `Q` 또는 `←` (이전), `W` 또는 `→` (다음)
- 헤더 중앙의 진행 표시 (예: `3 / 47`) 로 현재 위치 확인

### Image List 패널

왼쪽 사이드바의 이미지 아이콘 버튼을 클릭해 패널을 열 수 있습니다.

- **그리드 뷰 / 목록 뷰** 전환 버튼으로 보기 방식을 변경합니다.
- 썸네일 크기 슬라이더로 미리보기 크기를 조절합니다.
- 작업이 완료된 이미지에는 **체크 표시**와 **obj N** 카운트가 표시됩니다.
- 이미지 항목을 클릭하면 해당 이미지로 바로 이동합니다.

## 7. Label Viewer 패널

왼쪽 사이드바의 코드(`<>`) 아이콘 버튼을 클릭해 패널을 열 수 있습니다.

현재 이미지의 라벨링 데이터를 실시간으로 확인할 수 있습니다.

| 탭 | 내용 |
|----|------|
| **JSON** | 내부 저장 형식의 원본 데이터 |
| **YOLO** | YOLO 학습에 사용하는 텍스트 형식 |

각 탭에는 **복사** 버튼과 **다운로드** 버튼이 있어 현재 이미지의 파일 한 개를 바로 저장할 수 있습니다.

> [!NOTE]
> 전체 이미지를 한 번에 저장하려면 헤더의 **전체 저장 (ZIP)** 버튼을 사용하세요.

## 8. 저장 및 출력 형식

### 전체 저장

헤더의 **전체 저장 (ZIP)** 버튼을 클릭하거나 `Ctrl + S` (`Mac: Cmd + S`) 를 누릅니다.

`annotations_YYYY-MM-DD.zip` 파일이 다운로드됩니다.

### ZIP 내부 구조

```
annotations_2024-01-15.zip
├── json/                  ← 전체 이미지 (객체 없는 이미지 포함)
│   ├── image1.json
│   ├── image2.json
│   └── ...
└── labels/                ← 객체가 있는 이미지만 생성
    ├── image1.txt
    └── ...
```

### YOLO TXT 형식

한 줄에 객체 하나를 표현합니다.

```
class_idx  x_center  y_center  width  height
```

- 모든 좌표 값은 이미지 크기로 나눈 **정규화 값** (0.0 ~ 1.0)
- `class_idx` 는 Config 배열의 순서 (0부터 시작)

**예시**
```
0 0.512345 0.387612 0.123456 0.234567
1 0.234567 0.654321 0.098765 0.112233
```

### JSON 내부 형식

```json
{
  "image_path": "image1.jpg",
  "image_width": 1920,
  "image_height": 1080,
  "objects": [
    {
      "id": "obj_1705123456789",
      "className": "person",
      "bbox": [120.5, 45.2, 380.1, 520.8]
    }
  ]
}
```

- `bbox` 좌표는 픽셀 단위의 절대 좌표 `[x1, y1, x2, y2]`

## 9. 작업 이어하기

이전에 저장한 ZIP 파일을 이용해 작업을 재개하는 방법입니다.

1. 이전에 저장한 `annotations_YYYY-MM-DD.zip` 파일의 압축을 해제합니다.
2. 툴을 실행하고 Config 파일을 로드합니다.
3. **이미지 폴더 열기** 로 이전과 동일한 이미지 폴더를 선택합니다.
4. 헤더의 **라벨 폴더 열기** 를 클릭합니다.
5. 압축을 해제한 **폴더** 를 선택합니다 (폴더 안의 파일이 아닌 폴더 자체).
6. 툴이 자동으로 `json/` 하위 폴더를 감지하여 이전 어노테이션을 복원합니다.

완료되면 이미지 목록에 이전에 작업한 이미지들의 체크 표시가 나타납니다.

> [!IMPORTANT]
> 이미지 파일명과 JSON 파일명이 **정확히 일치** 해야 합니다.
> 예: `cat1.jpg` ↔ `cat1.json`
> 파일명이 다르면 해당 이미지의 라벨이 로드되지 않습니다.

> [!WARNING]
> **라벨 폴더 열기** 는 Config와 이미지 폴더를 모두 로드한 후에만 사용할 수 있습니다.

## 10. YOLO 학습 데이터 준비

저장된 ZIP의 `labels/` 폴더를 YOLO 학습에 바로 사용할 수 있습니다.

**필요한 3가지**

| 항목 | 설명 |
|------|------|
| `images/` | 원본 이미지 폴더 |
| `labels/` | ZIP에서 추출한 TXT 파일 폴더 |
| `data.yaml` | 클래스 정의 파일 (직접 작성) |

**data.yaml 작성 방법**

```yaml
path: /path/to/dataset   # 데이터셋 루트 경로
train: images            # 학습 이미지 폴더
val: images              # 검증 이미지 폴더 (별도 없으면 동일하게)

nc: 5                    # 클래스 수 (Config 배열 길이와 동일)
names:                   # Config 배열과 동일한 순서로 작성
  - person
  - car
  - truck
  - bicycle
  - motorcycle
```

> [!IMPORTANT]
> `names` 목록의 순서는 Config 파일의 클래스 배열 순서와 **반드시 동일** 해야 합니다.
> 순서가 다르면 잘못된 클래스로 학습됩니다.

**학습 명령어 예시 (Ultralytics YOLOv8)**

```bash
yolo detect train data=data.yaml model=yolov8n.pt epochs=100
```

## 11. 단축키 전체 목록

| 단축키 | 기능 |
|--------|------|
| `Q` / `←` | 이전 이미지 |
| `W` / `→` | 다음 이미지 |
| `1` ~ `9` | N번째 클래스 선택 + 그리기 모드 진입 |
| `Delete` / `Backspace` | 선택한 객체 삭제 |
| `Escape` | 동작 취소 / 선택 해제 |
| `Ctrl + Z` (Mac: `Cmd + Z`) | 실행 취소 |
| `Ctrl + S` (Mac: `Cmd + S`) | 전체 저장 (ZIP) |
| `Alt` + 드래그 | 캔버스 패닝 |
| 마우스 휠 | 줌 인 / 줌 아웃 |

> [!TIP]
> 숫자키로 클래스를 선택하면 그리기 모드까지 한 번에 진입할 수 있어 가장 빠른 라벨링 방법입니다.

## 12. 단축키 커스터마이징

기본 단축키가 불편하다면 직접 변경할 수 있습니다.

1. 헤더 오른쪽의 **톱니바퀴 아이콘** 을 클릭합니다.
2. 변경하고 싶은 기능 옆의 입력창을 클릭합니다.
3. 원하는 키를 누릅니다.
4. **저장** 버튼을 클릭합니다.

변경된 단축키는 브라우저의 localStorage에 저장되어 브라우저를 닫아도 유지됩니다.

**기본값으로 초기화** 버튼을 클릭하면 모든 단축키가 원래대로 돌아갑니다.

---

## 13. 클래스 색상 변경

각 클래스에 표시되는 색상을 원하는 색으로 바꿀 수 있습니다.

1. 오른쪽 패널 상단의 클래스 선택기 왼쪽에 있는 **색상 원** 을 클릭합니다.
2. 브라우저 색상 선택기에서 원하는 색을 고릅니다.
3. 변경 사항이 즉시 반영됩니다.

색상 설정은 localStorage에 저장되어 브라우저를 닫아도 유지됩니다.

## 14. 문제 해결 FAQ

| 증상 | 원인 | 해결 방법 |
|------|------|-----------|
| "이미지 폴더 열기" 버튼이 클릭되지 않음 | Config를 아직 로드하지 않음 | Config 파일을 먼저 로드하세요 |
| 폴더 선택 창이 열리지 않음 | `file://` 로 직접 파일을 열었음 | `python -m http.server 8080` 으로 실행하세요 |
| 라벨이 로드되지 않음 | 이미지 파일명과 JSON 파일명이 다름 | 파일명이 일치하는지 확인하세요 |
| YOLO TXT 파일이 없음 | 해당 이미지에 객체가 없음 | 정상 동작입니다. 객체가 있는 이미지만 TXT가 생성됩니다 |
| 박스가 너무 작다는 오류 | 클릭만 하고 드래그하지 않음 | 10×10 픽셀 이상이 되도록 드래그하세요 |
| 페이지를 닫을 때 경고가 뜸 | 저장하지 않은 변경 사항이 있음 | `Ctrl + S` 로 저장 후 닫으세요 |
| Chrome이 아닌 브라우저에서 폴더 선택 불가 | 브라우저 미지원 | Chrome 브라우저를 사용하세요 |
